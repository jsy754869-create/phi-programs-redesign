# Anduril — Rebooting the Arsenal (MediaAccordion) 측정값

URL: https://www.anduril.com/rebooting-the-arsenal ("Adherence to a lengthy bureaucratic process." 리스트)
측정 환경: 1512 × 797 뷰포트, 2026-10-21

## 구조
- 항목 5개. 각 항목은 `<button>`(aria-expanded) = border(1px 선) + header(번호, 제목) + content(설명).
- 12열 그리드(열 약 95.6px, 열 간격 18.3px), 좌우 여백 81.5px.
  - 번호 "01": 1열, 17.1px
  - 제목: 2~6열, 40.75px / 46.9px, 자간 -0.815px(-2%)
  - 설명: 7~12열(x 756, 화면 절반에서 시작), 17.1px / 20.5px. **제목과 같은 높이(y 50)에서 시작**해 오른쪽에서 아래로 펼쳐진다.
- 구분선: 1px, 불투명도 0.6. 선 아래 여백 48.9px, 항목 아래 패딩 65.2px.
- 닫힌 항목 높이 약 209px(제목 2줄 기준).

## 인터랙션
- 펼침: content의 height를 0 → scrollHeight로 tween. **800ms, easeOutSine = cubic-bezier(0.39, 0.575, 0.565, 1)**. 닫힘도 같은 값.
- 스크롤 트리거: 항목마다 진행도 p = (뷰포트 높이 − 항목 top) / 항목 높이 − 0.5.
  - **1.5 < p < 2**가 되는 순간 한 번만 자동으로 연다. 닫힌 높이 209px 기준으로 항목 top이 뷰포트 위에서 약 275~379px(화면 높이의 35~48%)에 왔을 때다.
  - **자동으로 닫지는 않는다.** 위로 다시 스크롤해도 읽은 항목은 열린 채로 남는다.
  - 한 프레임에 진행도가 0.5 넘게 뛰면(빠른 점프, 앵커 이동) 무시한다. 헤더 링크를 클릭한 직후 1초 동안도 무시한다.
- 클릭: 버튼 전체가 토글. 자동으로 열린 뒤에도 클릭하면 닫고 다시 열 수 있다.
- 부드러운 스크롤 라이브러리 Lenis를 사용한다.
- 모바일(768px 미만)에서는 레이아웃이 달라진다(별도 확인 필요).
