- 섹션 높이 3188px(뷰포트 약 4배). 안쪽 컨테이너는 `position: sticky; top: 0`, 높이 100vh, 세로 가운데 정렬, 패딩 192px 40px.
- 헤딩: 64px / 64px, 굵기 500, 자간 -3.2px(-5%), 색 #050419. 헤딩과 그리드 사이 96px.
- 그리드: 4열, 열 간격 40px, 항목 폭 328px.
  - 각 항목은 **왼쪽 1px 세로선(#E6E6E8)** + 왼쪽 패딩 24px. 선은 처음부터 4개 모두 보인다(빈 칸의 틀이 먼저 보임).
  - 아이콘 96×96px(아이소메트릭 선화) → 48px → 제목 24px/24px, 굵기 500, 자간 -0.96px → 20px → 설명 18px/25.2px, 색 #585765.

## 인터랙션 (GSAP, 화면 폭 1201px 이상에서만)
- 각 항목의 내용(아이콘·제목·설명)은 시작할 때 opacity 0, y +80px.
- 스크롤 진행도 u = (섹션 안에서 스크롤한 거리) / (섹션 높이 − 뷰포트 높이) → 0~1.
- 항목 하나의 몫 h = 1/4 = 0.25, 겹침 f = h × 0.3 = 0.075.
  - 항목 i의 구간: 시작 = i × h − (i > 0이면 f), 끝 = 시작 + h + f
  - 01: 0 ~ 0.325 / 02: 0.175 ~ 0.5 / 03: 0.425 ~ 0.75 / 04: 0.675 ~ 1.0
  - 앞 항목이 거의 다 올라왔을 때 다음 항목이 출발한다(구간 겹침 약 0.15).
- 구간 안에서 opacity 0 → 1, y 80 → 0, **power2.out**. 스크롤 위치에 직접 연결(scrub)되어 **위로 스크롤하면 거꾸로 사라진다.**
- 픽셀로 환산: 항목 하나가 다 올라오는 데 약 777px(뷰포트 1장 분량), 다음 항목은 약 598px마다 출발한다.
- 1200px 이하에서는 애니메이션 없이 모두 보인다.
